# Treningslogg

En enkel full-stack webapp for å logge treningsøkter — øvelse, vekt, reps og sett per dato.
Bygget som portefølje-prosjekt for å øve på backend-utvikling.

## Funksjoner
- Legg til treningsøkter (øvelse, vekt i kg, antall reps, antall sett, dato)
- Se en liste over loggede økter
- Slett økter

## Teknologier
- Node.js + Express (backend/API)
- SQLite (via better-sqlite3) for lagring
- Vanilla HTML, CSS og JavaScript (frontend)

## Kjøre prosjektet lokalt
1. Klon repoet: `git clone https://github.com/Gauseeban/treningslogg.git`
2. Installer avhengigheter: `npm install`
3. Start serveren: `node server.js`
4. Åpne `http://localhost:3000` i nettleseren
